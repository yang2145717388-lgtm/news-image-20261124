A program that draws a newspaper front page summing up the world news of Tuesday, 24 November 2026: Jensen Huang's return to Nvidia and the 31.5% share surge, the US blacklisting of chip firm Megaspeed, an Israeli strike in Gaza, suspected Iranian cyberattacks on tankers, Odesa's power crisis, a magnitude 5.3 quake in Nepal, and China's Shenzhou-24 launch — plus the day's briefs.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024, deterministic) to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when set. Requires Python 3.13 and Pillow 10.2.0; standard library only, no network.
